РОМАНТИЧЕСКИЙ САЙТ ДЛЯ Майя
===========================

КАК ОТКРЫТЬ И ПРОВЕРИТЬ
-----------------------
1. Откройте файл index.html двойным кликом (в Chrome, Edge, Safari или Firefox).
2. Нажмите на конверт. Он откроется, и появится сайт.
3. Вид как на телефоне: нажмите F12, затем значок телефона (Toggle device toolbar)
   и выберите iPhone SE или любой Android.
4. Если после изменений ничего не поменялось, обновите страницу с очисткой кэша: Ctrl + F5.

ЧТО ГДЕ МЕНЯТЬ
--------------
Все тексты и настройки находятся в файле config.js. Меняйте только текст внутри кавычек '...'.
  - name, nameGen      : как обращаться (Киса / Кисы)
  - startDate          : дата начала отношений, формат ГГГГ-ММ-ДД
  - typingLines        : текст, который печатается сам
  - photos             : фото (см. ниже)
  - reasons            : 100 причин (можно заменить на свои)
  - noTexts, yesMessage: надписи кнопок «Нет» и «Да»
  - finalTitle, finalText, signature: финальный экран
Цвета меняются в начале style.css (блок :root).
Заголовок вкладки браузера задаётся автоматически из имени в config.js.

ФОТО
----
1. Сожмите фото до ширины примерно 1200 px. Так сайт быстрее откроется на телефоне.
2. Положите их в папку photos и назовите, например, 1.jpg, 2.jpg, 3.jpg.
3. В config.js укажите путь в src:
     { src: 'photos/1.jpg', caption: 'Наше первое фото' },
   Пока src пустой, показывается красивая заглушка.
   Фото можно добавлять и убирать, количество любое.

МУЗЫКА
------
1. Положите файл в папку music и назовите song.mp3 (лучше до 10 МБ).
   Если файл называется иначе, поменяйте music в config.js.
2. Музыка включается при открытии конверта или кнопкой 🎵 справа внизу.
   Без файла сайт работает, а кнопка покажет подсказку «Музыка скоро будет».
Браузеры не разрешают музыке играть без нажатия, поэтому она стартует только после касания.
   
ЗАГРУЗКА В ИНТЕРНЕТ НАВСЕГДА: GITHUB PAGES (бесплатно)
------------------------------------------------------
1. Зарегистрируйтесь на github.com.
2. Нажмите New repository. Назовите, например, kisa. Выберите Public. Создайте репозиторий.
3. Нажмите Add file, затем Upload files. Перетащите СОДЕРЖИМОЕ папки site
   (index.html, style.css, script.js, effects.js, config.js, папки music и photos),
   а не саму папку site. Нажмите Commit changes.
4. Откройте Settings, затем Pages. В Source выберите Deploy from a branch,
   ветку main и папку / (root). Нажмите Save.
5. Через 1-2 минуты появится ссылка вида  ваш-логин.github.io/kisa  Её и отправьте.

ВАЖНО:
  - index.html должен лежать в корне репозитория, не внутри папки, иначе будет ошибка 404.
  - Репозиторий публичный: файлы (в том числе фото) технически может найти любой.
    Очень личные фото лучше не загружать.
  - Netlify Drop без регистрации удаляет сайт через час. Для постоянной ссылки
    используйте GitHub Pages или зарегистрируйтесь в Netlify и нажмите Make public.

КАК ОБНОВИТЬ САЙТ ПОСЛЕ ЗАГРУЗКИ
--------------------------------
На GitHub откройте репозиторий, нажмите Add file, затем Upload files и загрузите новые файлы
поверх старых. Ссылка останется прежней. Изменения появятся через 1-2 минуты.

СЧЁТЧИК
-------
Считает от startDate до текущего момента и работает всегда. После годовщины
отсчёт «до годовщины» сам переключается на следующий год.
